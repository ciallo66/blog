# Langchain
**介绍**：LangChain 是用于开发大模型应用的框架，封装了很多用于智能体开发的工具，便于开发。  

相较于传统智能体开发：
>1.模型调用：从手动编写请求、处理响应，变为通过统一接口调用模型。 
>2.工具定义：从手动编写工具描述和参数结构，变为通过 @tool 自动生成。  
>3.工具注册：从手动组织工具信息并传给模型，变为统一交给 Agent 管理。
>4.工具执行：从手动解析调用请求、匹配函数和传递参数，变为框架自动调度执行。
>5.Agent 执行流程：从手动编写模型与工具之间的循环，变为由 Agent 自动管理执行流程。
>6.消息与状态管理：从手动组织消息和维护对话状态，变为使用框架提供的消息类型与状态机制。
>7.流式输出：从手动处理流式响应，变为使用框架提供的流式接口。 




基础概念：LangChain 的作用、核心组件、整体工作流程。
模型调用：接入 OpenAI、DeepSeek 等模型，统一模型调用接口。
Prompt 提示词：提示词模板、变量传递、结构化输出。
LCEL 链式调用：使用管道组合提示词、模型、解析器等组件。
输出解析：将模型输出转换为字符串、JSON、指定的数据结构。
工具调用：定义工具、参数 Schema、工具注册，让模型选择并调用工具。
RAG 检索增强：文档加载、文本切分、Embedding、向量存储、检索与问答。
LangGraph 与 Agent：多步骤任务、状态管理、循环执行、条件分支、人工介入。

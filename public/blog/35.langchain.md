# Langchain

**介绍**：LangChain 是用于开发大模型应用的框架，封装了很多用于智能体开发的工具，便于开发。

相较于传统智能体开发：

> 1. 模型调用：从手动编写请求、处理响应，变为通过统一接口调用模型。
> 2. 工具定义：从手动编写工具描述和参数结构，变为通过 `@tool` 自动生成。
> 3. 工具注册：从手动组织工具信息并传给模型，变为统一交给 Agent 管理。
> 4. 工具执行：从手动解析调用请求、匹配函数和传递参数，变为框架自动调度执行。
> 5. Agent 执行流程：从手动编写模型与工具之间的循环，变为由 Agent 自动管理执行流程。
> 6. 消息与状态管理：从手动组织消息和维护对话状态，变为使用框架提供的消息类型与状态机制。
> 7. 流式输出：从手动处理流式响应，变为使用框架提供的流式接口。

## 一、工具

一句话主线：**`@tool` 定义 → `bind_tools()` 交给模型 → `ToolNode` 执行 → `create_agent()` 自动跑完整个循环。**

```text
@tool 定义工具
      ↓
bind_tools() 把工具 Schema 绑定给模型
      ↓
模型返回 Tool Call（只说要调啥，不执行）
      ↓
ToolNode 执行工具 → 结果回传模型
      ↓
create_agent() 管理"模型 ↔ 工具"循环，直到得出最终答案
```

### 1. `@tool` — 定义工具

- **用法**：装饰器，写在 Python 函数定义的上一行。
- **作用**：从函数名、docstring 和类型注解，自动生成工具的名称、描述和参数 Schema（即原本要手写的工具定义）。
- **注意**：docstring 决定模型知不知道“这工具干嘛用”，类型注解决定参数结构。两者写得不准，模型就会调错或不调。

### 2. `bind_tools()` — 把工具交给模型

- **用法**：`model.bind_tools(tools)`。
- **作用**：把工具的名称、描述和参数 Schema 绑定给模型，由模型自行决定调不调、调哪个。
- **注意**：模型只返回 **Tool Call（工具名 + 参数）**，不返回执行结果。执行工具和后续再调模型，都得另外处理。

### 3. `ToolNode` — 执行工具（LangGraph）

- **用法**：`ToolNode(tools)`，作为 LangGraph 图中的一个节点。
- **作用**：读取状态里的 Tool Call → 调用对应工具 → 把结果写回图的状态。
- **注意**：只负责执行，不负责决定下一步。通常配合条件边，判断有没有 Tool Call，再决定走工具节点还是结束流程。

### 4. `create_agent()` — 自动跑完整个循环

- **用法**：`create_agent(model, tools)` 构建 Agent，`agent.invoke(input)` 输入用户消息并启动。
- **作用**：封装完整流程：模型调用 → 判断是否调工具 → 执行工具 → 结果回传模型 → 循环，直到模型给出最终答案。
- **注意**：传入模型和工具即可，不用自己写 Agent Loop（工具匹配、结果回传、循环终止都交给它）。

### 小结：各工具替你接手了哪些手工活

| 工具 | 原生开发要手动做 | 它替你做了 |
| --- | --- | --- |
| `@tool` | 编写工具名称、描述、参数 Schema | 从函数签名和 docstring 自动生成 |
| `bind_tools()` | 把工具定义转成模型 API 格式并拼进请求 | 统一绑定 |
| `ToolNode` | 解析 Tool Call、匹配函数、传参、回传结果 | 在图中自动执行 |
| `create_agent()` | 手写模型与工具的循环及终止判断 | 整个 Agent Loop |

## 二、学习提纲

- 基础概念：LangChain 的作用、核心组件、整体工作流程。
- 模型调用：接入 OpenAI、DeepSeek 等模型，统一模型调用接口。
- Prompt 提示词：提示词模板、变量传递、结构化输出。
- LCEL 链式调用：使用管道组合提示词、模型、解析器等组件。
- 输出解析：将模型输出转换为字符串、JSON、指定的数据结构。
- 工具调用：定义工具、参数 Schema、工具注册，让模型选择并调用工具。
- RAG 检索增强：文档加载、文本切分、Embedding、向量存储、检索与问答。
- LangGraph 与 Agent：多步骤任务、状态管理、循环执行、条件分支、人工介入。

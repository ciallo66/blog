# Java

## 一.基础语法（数据类型、变量、运算符、流程控制、数组、方法、类型转换。）

基本语法：变量、数据类型、运算符、流程控制、数组、方法。

面向对象：类与对象、封装、继承、多态、抽象类、接口。

关键字与修饰符：static、final、this、super、访问修饰符。

字符串与常用类：String、StringBuilder、包装类、基本类型与引用类型。

异常处理：异常体系、try-catch-finally、throw、throws、自定义异常。

泛型与语言特性：泛型、枚举、注解、内部类、Lambda 表达式。

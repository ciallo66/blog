# python的学习
>Python 注重开发效率，语法简洁，动态类型语言，不会提前检查类型，开发更方便快捷
>目前 Python 主要应用于人工智能、数据分析、自动化脚本、爬虫、Web 后端开发等领域，尤其在 AI 等智能体研发有独有的优势。

## 一.基础语法
### 1. 变量与数据类型
Python 不需要提前声明变量类型，直接赋值即可。常用数据类型主要有：
| 类型    | 作用   |
| ----- | ---- |
| int   | 整数   |
| float | 小数   |
| str   | 字符串  |
| bool  | 判断真假 |
| None  | 表示空值 |

**注意：**
* Python 是动态类型语言，变量类型会根据赋值自动变化。
* 不同类型之间经常需要转换，例如字符串转数字。

### 2. 条件判断与循环
Python 通过条件和循环控制程序执行流程。
| 功能               | 作用         |
| ---------------- | ---------- |
| if / elif / else | 根据条件执行不同代码 |
| for              | 遍历数据       |
| while            | 满足条件持续执行   |
| break            | 结束循环       |
| continue         | 跳过当前循环     |

**注意：**
* Python 使用缩进表示代码层级，不使用大括号。
* 循环主要用于处理列表、文件、数据等批量操作。

## 二.数据结构
Python 常用数据结构主要包括列表（list）、字典（dict）、元组（tuple）、集合（set），用于不同场景的数据存储和处理。(只有列表和元组可以进行下标访问)

### 1. 列表（list）
列表用于存储一组有序、可修改的数据，是开发中最常用的数据结构。

基本格式：
```python
list_name = [数据1, 数据2, 数据3]
```

常用操作：
```python
list.append()    # 添加数据
list.remove()    # 删除数据
list[index]      # 根据索引获取数据
list[index] = x  # 修改数据
```
常用于保存用户列表、商品列表等需要遍历和修改的数据。

### 2. 字典（dict）
字典通过 key-value（键值对）保存数据，适合根据标识快速获取信息。

基本格式：
```python
dict_name = {
    "key": "value"
}
```

常用操作：
```python
dict["key"]          # 获取数据
dict["key"] = value  # 修改或添加数据
dict.get("key")      # 安全获取数据
```
实际开发中大量使用，例如接口数据、用户信息、配置文件等。
### 3. 元组（tuple）
元组用于保存不可修改的数据。

基本格式：
```python
tuple_name = (数据1, 数据2)
```

特点：
* 有序
* 不可修改

适合保存固定数据。
### 4. 集合（set）
集合用于存储不重复的数据，常用于去重。

基本格式：
```python
set_name = {数据1, 数据2}
```

常用操作：
```python
set.add()       # 添加数据
set.remove()    # 删除数据
```
### 5. 实际开发选择
| 数据结构  | 主要用途          |
| ----- | ------------- |
| list  | 管理一组可变化的数据    |
| dict  | 根据 key 快速查询数据 |
| tuple | 保存固定不变的数据     |
| set   | 数据去重          |

实际开发中最常用的是 **list 和 dict**，尤其是在接口开发、数据处理、业务逻辑中大量出现。

## 四.面向对象编程（OOP）
Python 是一种支持面向对象编程的语言，OOP 主要用于将数据和功能封装在一起，让代码结构更加清晰，提高代码复用性和维护性。在实际项目中，常用于管理用户、商品、订单等具有属性和行为的业务对象。
### 1. 类与对象
**概念**：类是创建对象的模板（图纸），对象是类创建出来的具体实例。  
**理解**: 如果需要封装很多的函数（方法）就需要使用类，类里面的方法第一个参数必是 `self`。`__init__`是类里面的构造函数用于初始化数据，这里面的数据都可以被类里面的方法共用的，类似一个小仓库
基本格式：
```python
class 类名:
    def 方法名(self):
        代码
```

主要概念：
| 内容         | 说明                  |
| ---------- | ------------------- |
| 类（class）   | 定义对象的结构和功能          |
| 对象（object） | 根据类创建的具体实例          |
| 属性         | 对象保存的数据，例如用户名称、商品价格 |
| 方法         | 对象可以执行的操作           |

### 2.鸭子类型
| 内容       | 说明                                                    |
| -------- | ----------------------------------------------------- |
| 定义       | 不关注对象是什么类型，只关注对象是否具有需要的方法                             |
| 核心思想     | “只要行为像，就可以当作同一种对象使用”                                  |
| 特点       | 不进行严格类型检查，提高代码灵活性                                     |
| 示例       | 函数需要 `speak()` 方法，不管对象是 Dog 还是 Cat，只要有 `speak()` 就能调用 |
| Python特点 | Python 是动态类型语言，天然支持鸭子类型                               |

**常用语法**（只列日常最常用的）：

### 2. 异常处理
#### (1)基础异常处理
异常处理用于捕获程序运行中的错误，避免程序因为异常直接终止,和js里面的try...catch类似。  
基本格式：
```python
try:
    执行代码
except:
    错误处理
```

主要结构：
| 关键字     | 作用         |
| ------- | ---------- |
| try     | 执行可能出错的代码  |
| except  | 捕获并处理异常    |
| finally | 无论是否异常都会执行 |

#### (2)Py内置的错误处理
Python 自带一整套内置错误类型，它们组成一棵"家族树"：

```py
BaseException（真正的总祖先，管系统级退出等，平时不用碰）
└── Exception（所有"普通错误"的老祖宗，我们平时 catch 的就是它）
    ├── ValueError        值不对（比如 int("abc") 转不了）
    ├── TypeError         类型不对（比如给数字加字符串）
    ├── KeyError          字典里没有这个键
    ├── IndexError        列表下标越界（list[100] 超出长度）
    ├── ZeroDivisionError 除数为 0
    ├── ConnectionError   网络连接失败
    └── ...（还有很多，用到再查）
```

**为什么认识它们**：`except` 可以按错误类型**精准捕获**，让不同的错误走不同的处理：

```python
try:
    num = int("abc")            # 会抛 ValueError
except ValueError as e:         # 精准接住"值不对"
    print("转不了数字：", e)
except TypeError:               # 精准接住"类型不对"
    print("类型不对")
except Exception as e:          # 兜底网：接住所有漏网之鱼
    print("其他错误：", e)
```

>**注意**：`except` 从上到下匹配，所以**具体类型写在前面，`Exception` 兜底写在最后**。如果把 `Exception` 写最前面，它会先把所有错误都接走，后面的 `except ValueError` 永远轮不到。

## 六.迭代器
### 1.可迭代对象 vs 迭代器
- **可迭代对象（Iterable）**：能被 `for` 遍历或传给 `iter()` 的对象（list/dict/set/str/range/文件等）。数据早已在内存，**可反复遍历、不省内存**。
- **迭代器（Iterator）**：`iter(obj)` 得到的"游标"，记住位置、按需吐值：**只能往前、一次性、省内存**（所以 list/dict 这类容器本身不是迭代器）。
- 迭代器自己也能被 `for` 遍历，故迭代器是特殊的可迭代对象；dict 遍历出的是**键**，str 遍历出的是**字符**。

```python
fruits = ["苹果", "香蕉", "西瓜"]
it = iter(fruits)          # 列表本身可反复 for，迭代器才是一次性"游标"
print(next(it))            # 苹果 —— 每次 next 吐一个，用光抛 StopIteration
print(next(it))            # 香蕉
for f in fruits:
    print(f)               # 苹果 香蕉 西瓜（列表没被消耗，还能再遍历）
# for 本质 = 先 iter() 拿迭代器 → 循环 next(it) → 捕获 StopIteration 自动结束
```

### 2.自定义迭代器（原理）
自己造迭代器只需两个方法：`__iter__` **必须返回一个迭代器**（自身就是迭代器就 `return self`；若想做成"只可迭代"的容器类则返回别的迭代器，如 `iter(self.data)`）；`__next__` 定义取下一个值，取完 `raise StopIteration` 让 for 结束。

```python
class MyCounter:                        # 效果等价于 range(1, n+1)
    def __init__(self, max_num):
        self.max_num, self.current = max_num, 1
    def __iter__(self):
        return self                     # 必须返回一个迭代器
    def __next__(self):
        if self.current > self.max_num:
            raise StopIteration         # 取完叫停 for
        v = self.current
        self.current += 1
        return v

for n in MyCounter(3):
    print(n)                            # 1 2 3（for 后对象已耗尽，一次性）
```

### 3.生成器（yield）
生成器是写迭代器最省事的方式：函数体里出现 `yield` 即成生成器函数，**调用时不执行函数体**，只返回生成器对象（真正的迭代器），首次 `next()`/`for` 才开始跑。`yield` 交出值并**暂停保存现场**，下次从断点继续；`return` 则直接结束。  
**作用**：① 惰性省内存（海量数据、大文件逐条产出）② 能写"无限"序列（配合 itertools 按需截取）③ 一个 yield 免去 __iter__/__next__ 那套状态管理。  
**生成器表达式** `(x for x in ...)`：圆括号推导式，惰性省内存，但**只能消费一次**（列表推导式可反复遍历）。

```python
def count_up(n):                        # 生成器函数，等价于上面的 MyCounter
    i = 1
    while i <= n:
        yield i                         # 交出 i 并保存现场，下次从这继续
        i += 1

g = count_up(3)                         # 此刻函数体还没执行
print(next(g))                          # 1（第一次 next 才开始跑）
print(list(count_up(3)))                # [1, 2, 3]（for/list 会自动处理 StopIteration）

def read_lines(path):                   # 逐行读大文件，内存里始终只有一行
    with open(path, encoding="utf-8") as f:
        for line in f:
            yield line.strip()

s = (x * x for x in range(5))           # 生成器表达式
print(sum(s))                           # 30（0+1+4+9+16），之后 s 已耗尽
```

> 进阶（用到再查）：生成器还支持 `.send()`/`.close()`/`.throw()`/`yield from`；生成器里 `return 值` 会放进抛出的 `StopIteration`。

### 4.标准库高效迭代器（itertools 工具箱）

| 函数 | 作用 | 示例 | 输出示例 | 常见场景 |
|------|------|------|----------|----------|
| `count(start=0, step=1)` | 无限计数器 | `count(1)` | `1 2 3 4 ...` | 自增 ID、编号、无限循环 |
| `chain(*iterables)` | 拼接多个可迭代对象 | `chain([1,2],[3,4])` | `1 2 3 4` | 合并多个列表、多个查询结果 |
| `islice(iterable, stop)` | 对迭代器进行切片 | `islice(g, 5)` | `0 1 2 3 4` | 截取生成器、分页读取、限制遍历数量 |
| `combinations(iterable, r)` | 返回所有不重复组合 | `combinations([1,2,3],2)` | `(1,2) (1,3) (2,3)` | 排列组合、算法、面试题 |
| `product(*iterables)` | 返回笛卡尔积 | `product("AB",[1,2])` | `('A',1) ('A',2) ('B',1) ('B',2)` | 多层循环、参数组合、生成测试数据 |
| `cycle(iterable)` | 无限循环遍历序列 | `cycle(["A","B","C"])` | `A B C A B C ...` | 轮播、循环任务、重复数据 |
| `zip_longest(*iterables)` | 长度不同也能同时遍历 | `zip_longest([1,2],["A"])` | `(1,'A') (2,None)` | 合并长度不同的数据、数据对齐 |

## 七.装饰器
### 1.普通写法
**介绍**：装饰器用于在不修改原函数代码的前提下，为函数动态添加额外功能。
**本质**：装饰器本质上利用闭包和高阶函数，对函数进行包装，返回增强后的新函数，实现功能增强和代码复用。
```python
def decorator(func):      # 加工环境，接收原函数
    def wrapper():        # 加工厂
        print("开始")      
        func()            # 原函数
        print("结束")      
    return wrapper        # 返回加工后的函数
# wrapper 新函数替代了原先的函数 func

```
### 2.语法糖 @
**介绍**： @ 是装饰器的语法糖，会在函数定义完成后自动将函数传入装饰器进行包装（相当于自动执行 函数 = decorator(函数)），使代码更加清晰、易读、易维护。
```python
@decorator
def hello():
    print("Hello")
#不使用语法糖还需要 hello = decorator(hello)
```
